Design — New Agent Lineup (Sub-project 1)

4 agen baru menggantikan Quant, Newsroom, Economist, Critic

🔬 DeepResearch Agent
Menggantikan: Quant + Economist
Tools yang dipakai:
  • yfinance: income statement, balance sheet, cash flow 5 tahun
  • yfinance: analyst price targets + recommendations
  • Hitung tren: ROE, profit margin, revenue growth CAGR
  • Korelasi makro (tetap ada)
OUTPUT JSON:
valuation, growth_trend, financial_health,
analyst_consensus, macro_context
📰 NewsIntelligence Agent
Menggantikan: Newsroom (lebih smart)
Tools yang dipakai:
  • Serper/DDG: 15 berita terbaru (dari 10)
  • Klasifikasi event: earnings/M&A/manajemen/regulasi
  • Sentiment per artikel (bukan aggregate saja)
  • Deteksi anomali: unusual volume + news spike
OUTPUT JSON:
sentiment_score, event_type, key_events,
risk_signals, catalyst_signals
⚡ Strategy Agent
BARU — Terinspirasi ValueCell
Input dari DeepResearch + NewsIntelligence:
  • Generate entry price zone (support level)
  • Exit target (resistance + analyst target)
  • Stop loss level (% dari entry)
  • Time horizon (short/medium/long term)
  • Position sizing suggestion (% portfolio)
OUTPUT JSON:
entry_zone, exit_target, stop_loss,
time_horizon, position_size, rationale
⚖️ FinalVerdict Agent
Menggantikan: Critic (lebih tajam)
Input dari semua 3 agen di atas:
  • Devil's advocate: tantang setiap asumsi
  • Conviction score 1–10 (bukan cuma BUY/HOLD/SELL)
  • Risk/Reward ratio konkret
  • Skenario bull case vs bear case
  • Investment memo final profesional
OUTPUT JSON:
verdict, conviction_score, risk_reward,
bull_case, bear_case, investment_memo
Pipeline Flow
DeepResearch
→
NewsIntelligence
→
Strategy
→
FinalVerdict
Sequential dengan jeda 5s antar agen • SSE streaming tetap sama • Output Bahasa Indonesia
📋 UI yang berubah: Nama agen di feed panel + section baru "Trading Strategy" (entry/exit/stop loss) + Conviction Score di verdict box.
✅ Yang tetap sama: Bloomberg dark theme, SSE pipeline, Plotly charts, Python code tab.

Design — Data Flow & Tools (Sub-project 1)

Apa yang diambil, dari mana, dan siapa yang pakai

Tools Layer — Yang Berubah di stock_tools.py
get_market_data() — UPGRADE
  • Income statement 5 tahun (ticker.financials)
  • Balance sheet 5 tahun (ticker.balance_sheet)
  • Cash flow 5 tahun (ticker.cashflow)
  • Analyst targets (ticker.analyst_price_targets)
  • Recommendations (ticker.recommendations)
  • Hitung ROE trend, margin trend, CAGR revenue
get_news_sentiment() — UPGRADE
  • Fetch 15 artikel (dari 10)
  • Klasifikasi event per artikel:
    earnings / M&A / mgmt / regulatory / macro
  • Sentiment score per artikel
  • Flag anomali: volume spike + news spike
get_macro_indicators() — DIHAPUS (digabung ke DeepResearch via get_market_data macro_context)
Pipeline — Data yang Mengalir Antar Agen
DeepResearch
~30s
→
OUTPUT: valuation, growth_trend, financial_health, analyst_consensus, macro_context, current_price, ohlcv
NewsIntelligence
~20s
→
OUTPUT: sentiment_score, event_type, key_events, risk_signals, catalyst_signals, anomaly_detected
Strategy
~20s
→
INPUT: DeepResearch + NewsIntelligence
OUTPUT: entry_zone, exit_target, stop_loss, time_horizon, position_size, rationale
FinalVerdict
~25s
→
INPUT: semua 3 agen di atas
OUTPUT: verdict (BUY/HOLD/SELL), conviction_score (1-10), risk_reward, bull_case, bear_case, investment_memo
Total estimasi: ~95–120 detik • Sequential dengan jeda 5s antar agen (rate limit guard) • SSE streaming ke frontend real-time
SSE Events — Tidak Berubah + 2 Event Baru
Tetap sama:
step → update status agen
log → pesan progres
chart → Plotly JSON
code → Python snippet
done → pipeline selesai
error → error handler
Baru:
strategy → entry/exit/stop loss data
verdict → conviction + bull/bear case

# Autoresearch Program — Alfred (TaskCore)

## Current Hypothesis

**H-001** (Baseline): Breaking complex goals into <= 3 actionable next steps with explicit due dates increases task completion rate.

## Metric

Task completion rate — user marks tasks done vs. abandons/ignores them

## Baseline Approach

- Always infer priority + due date and confirm the inference
- Group tasks by priority (Critical > High > Medium > Low)
- Surface overdue items at the top of every list view
- Ask one clarifying question rather than guessing on destructive actions

## Next Experiments

- [ ] **E-001**: Proactively group tasks by energy level (deep-focus vs. quick wins) in the default list view.
- [ ] **E-002**: Offer a "top 3 for today" briefing at the start of every session without being asked.
- [ ] **E-003**: Detect when the same task has been pushed 3+ times and surface a gentle nudge.

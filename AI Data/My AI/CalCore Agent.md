## What CalCore Does

- Connect to Google Calendar (read + write)
- Create, update, delete calendar events
- View today's schedule and weekly overview
- Schedule reminders and recurring events
- Suggest time slots for tasks and study blocks

## Quick Commands

| Say | Does |
|-----|------|
| `hari ini` | List today's events |
| `minggu ini` | Full week overview |
| `tambah acara: [name] [date] [time]` | Creates a new event |
| `hapus [event name]` | Removes an event |
| `waktu kosong besok` | Finds free slots tomorrow |

## Time Management Tip

> *"The goal isn't to fill every slot — it's to protect the ones that matter."*

Use CalCore to block **2-hour deep work windows** 3 days before each deadline. This prevents the last-minute crunch pattern.

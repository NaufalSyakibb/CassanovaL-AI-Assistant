### **3. MEKANISME KOLABORASI**
#### **A. Dynamic Routing**
- FIA-Ω menganalisis input pengguna dan mengaktifkan subagents yang relevan.
  - Contoh:
    - *"Bagaimana cara meningkatkan penjualan?"* → FIA-Biz + FIA-Creative + FIA-Research.
    - *"Tulis email ke investor tentang peluang bisnis kopi"* → FIA-Persona + FIA-Biz.
    - *"Beri saya ide paling gila untuk bisnis kopi"* → FIA-Wildcard + FIA-Creative.

#### **B. Parallel & Sequential Processing**
- **Parallel:** Subagents bekerja secara bersamaan (e.g., FIA-Biz menganalisis pasar sementara FIA-Creative brainstorming ide).
- **Sequential:** Output satu subagent menjadi input untuk subagent lain (e.g., FIA-Research → FIA-Biz → FIA-Exec).

#### **C. Conflict Resolution**
- Jika dua subagents memberikan output bertentangan (e.g., FIA-Biz menyarankan scaling cepat, FIA-Exec memperingatkan risiko cash flow), FIA-Ω akan:
  1. Menyajikan kedua opsi beserta pro/con.
  2. Meminta klarifikasi dari pengguna.
  3. Mensintesis solusi hybrid jika memungkinkan.

#### **D. Memory & Context Retention**
- **Short-Term Memory:** Menyimpan konteks percakapan selama sesi (e.g., jika pengguna menyebutkan "bisnis kopi" di awal, FIA akan mengingatnya di seluruh sesi).
- **Long-Term Memory:** Menyimpan preferensi dan pola pengguna (e.g., Ferry Irwandi lebih suka ide-ide yang scalable dan berbasis komunitas).

### **Kode Visualisasi (Simulasi)**
```python
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

# Load data (ganti 'real_madrid_2016_2017.csv' dengan nama file Anda)
df = pd.read_csv('real_madrid_2016_2017.csv')

# 1. Distribusi Gol per Pemain
plt.figure(figsize=(10, 6))
sns.histplot(df['Gol'], bins=15, kde=True, color='blue')
plt.title('Distribusi Gol Pemain Real Madrid 2016-2017')
plt.xlabel('Jumlah Gol')
plt.ylabel('Jumlah Pemain')
plt.show()

# 2. Heatmap Korelasi
plt.figure(figsize=(10, 6))
corr = df[['Gol', 'Assist', 'Kartu Kuning', 'Kartu Merah', 'Pertandingan', 'Usia']].corr()
sns.heatmap(corr, annot=True, cmap='coolwarm', center=0)
plt.title('Heatmap Korelasi Real Madrid 2016-2017')
plt.show()

# 3. Bar Chart Pemain dengan Gol Terbanyak
top_scorers = df.sort_values('Gol', ascending=False).head(10)
plt.figure(figsize=(10, 6))
sns.barplot(x='Gol', y='Nama Pemain', data=top_scorers, palette='viridis')
plt.title('Top 10 Pencetak Gol Real Madrid 2016-2017')
plt.xlabel('Jumlah Gol')
plt.ylabel('Nama Pemain')
plt.show()

# 4. Scatter Plot: Usia vs Gol
plt.figure(figsize=(10, 6))
sns.scatterplot(x='Usia', y='Gol', data=df, hue='Posisi', s=100)
plt.title('Hubungan Usia dan Gol Real Madrid 2016-2017')
plt.xlabel('Usia')
plt.ylabel('Jumlah Gol')
plt.show()
```

## What Da Vinci Does

- Creative brainstorming for any idea or problem
- Lateral thinking — reframes problems from unexpected angles
- Concept generation: 3 versions of any idea
- Design thinking facilitation
- Business/project ideation

---

## Quick Commands

| Say | Does |
|-----|------|
| `brainstorm: [idea]` | Generates multiple creative angles |
| `reframe: [problem]` | Sees the problem differently |
| `3 approaches for [X]` | Three distinct ways to tackle something |
| `creative brief: [project]` | Full creative document for a project |
| `what if [X]` | Explores a hypothetical scenario |

- Side project brainstorming
- Design Thinking assignments
- Leadership class case generation

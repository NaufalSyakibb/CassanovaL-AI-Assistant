## ✅ **Perbaikan `MenuItem.java`**
**Masalah di Kode Kamu:**
1. **Konstruktor kedua tidak menginisialisasi `stok`** (selalu `0`).
2. **Method `displayinfo()` typo** (harus `displayInfo()`).
3. **Tidak ada validasi** (harga/stok negatif? kategori tidak valid?).
4. **Tidak ada constructor overloading** (spesifikasi wajib 2 konstruktor).

**Versi Perbaikan:**
```java
public class MenuItem {
    private String nama;
    private double harga;
    private String kategori;
    private int stok;

    // Constructor 1: Stok default 0
    public MenuItem(String nama, double harga, String kategori) {
        this(nama, harga, kategori, 0); // Panggil constructor 2
    }

    // Constructor 2: Dengan stok awal
    public MenuItem(String nama, double harga, String kategori, int stok) {
        if (harga < 0) throw new IllegalArgumentException("Harga tidak boleh negatif");
        if (stok < 0) throw new IllegalArgumentException("Stok tidak boleh negatif");
        if (!kategori.equals("Makanan") && !kategori.equals("Minuman") && !kategori.equals("Snack")) {
            throw new IllegalArgumentException("Kategori harus Makanan/Minuman/Snack");
        }

        this.nama = nama;
        this.harga = harga;
        this.kategori = kategori;
        this.stok = stok;
    }

    // Getter (semua wajib)
    public String getNama() {
        return nama;
    }

    public double getHarga() {
        return harga;
    }

    public String getKategori() {
        return kategori;
    }

    public int getStok() {
        return stok;
    }

    // Setter (hanya yang diizinkan spesifikasi)
    public void setHarga(double hargaBaru) {
        if (hargaBaru < 0) throw new IllegalArgumentException("Harga tidak boleh negatif");
        this.harga = hargaBaru;
    }

    // Method untuk mengelola stok
    public void tambahStok(int jumlah) {
        if (jumlah <= 0) throw new IllegalArgumentException("Jumlah harus positif");
        this.stok += jumlah;
    }

    public boolean kurangiStok() {
        if (stok <= 0) return false;
        stok--;
        return true;
    }

    public boolean isAvailable() {
        return stok > 0;
    }

    // Method untuk menampilkan info
    public void displayInfo() {
        System.out.printf("%-20s | Rp%-10.0f | %-10s | Stok: %d%n", nama, harga, kategori, stok);
    }
}
```

> 💡 **Common Mistake:**
> - **Constructor overloading sering dilupakan** → Ingat: Jika spesifikasi minta 2 konstruktor, wajib ada keduanya.
> - **Validasi input diabaikan** → Di dunia nyata, input negatif bisa bikin sistem error. Selalu validasi!
>
> 🔥 **Pro Tip:**
> - Gunakan `this()` untuk memanggil constructor lain (seperti di atas) agar kode DRY (Don’t Repeat Yourself).
> - Format string dengan `printf` untuk output yang rapi dan konsisten.

```java
public class Customer {
    private String nama;
    private String nim;
    private double saldo;
    private int poin;

    // Constructor 1: Saldo dan poin mulai dari 0
    public Customer(String nama, String nim) {
        this(nama, nim, 0.0);
    }

    // Constructor 2: Dengan saldo awal
    public Customer(String nama, String nim, double saldoAwal) {
        if (saldoAwal < 0) throw new IllegalArgumentException("Saldo awal tidak boleh negatif");
        this.nama = nama;
        this.nim = nim;
        this.saldo = saldoAwal;
        this.poin = 0;
    }

    // Getter
    public String getNama() {
        return nama;
    }

    public String getNim() {
        return nim;
    }

    public double getSaldo() {
        return saldo;
    }

    public int getPoin() {
        return poin;
    }

    // Method untuk top up saldo
    public void topUpSaldo(double jumlah) {
        if (jumlah <= 0) {
            System.out.println("Error: Jumlah top up harus positif");
            return;
        }
        saldo += jumlah;
        System.out.printf("Top up berhasil. Saldo baru: Rp%.0f%n", saldo);
    }

    // Method untuk bayar
    public boolean bayar(double jumlah) {
        if (jumlah <= 0) {
            System.out.println("Error: Jumlah pembayaran harus positif");
            return false;
        }
        if (saldo < jumlah) {
            System.out.println("Error: Saldo tidak cukup");
            return false;
        }
        saldo -= jumlah;
        return true;
    }

    // Method untuk menambah poin
    public void tambahPoin(int poin) {
        if (poin <= 0) throw new IllegalArgumentException("Poin harus positif");
        this.poin += poin;
    }

    // Method untuk menampilkan info
    public void displayInfo() {
        System.out.printf("Nama: %-15s | NIM: %-10s | Saldo: Rp%-10.0f | Poin: %d%n", nama, nim, saldo, poin);
    }
}
```

```java
public class Order {
    private String orderId;
    private Customer customer;
    private MenuItem[] items;
    private int jumlahItem;
    private String status;

    public Order(String orderId, Customer customer) {
        this.orderId = orderId;
        this.customer = customer;
        this.items = new MenuItem[10]; // Maksimal 10 item
        this.jumlahItem = 0;
        this.status = "MENUNGGU";
    }

    // Getter
    public String getOrderId() {
        return orderId;
    }

    public Customer getCustomer() {
        return customer;
    }

    public String getStatus() {
        return status;
    }

    public int getJumlahItem() {
        return jumlahItem;
    }

    // Method untuk menambah item
    public boolean tambahItem(MenuItem item) {
        if (!status.equals("MENUNGGU")) {
            System.out.println("Error: Pesanan tidak bisa diubah (status: " + status + ")");
            return false;
        }
        if (jumlahItem >= 10) {
            System.out.println("Error: Pesanan penuh (maksimal 10 item)");
            return false;
        }
        if (!item.isAvailable()) {
            System.out.println("Error: Item " + item.getNama() + " tidak tersedia");
            return false;
        }
        items[jumlahItem] = item;
        jumlahItem++;
        return true;
    }

    // Method untuk hitung total
    public double hitungTotal() {
        double total = 0;
        for (int i = 0; i < jumlahItem; i++) {
            total += items[i].getHarga();
        }
        return total;
    }

    // Method untuk proses order
    public boolean prosesOrder() {
        if (!status.equals("MENUNGGU")) {
            System.out.println("Error: Pesanan sudah diproses/dibatalkan");
            return false;
        }
        double total = hitungTotal();
        if (!customer.bayar(total)) {
            return false;
        }
        // Kurangi stok dan tambah poin
        for (int i = 0; i < jumlahItem; i++) {
            items[i].kurangiStok();
            customer.tambahPoin(1); // 1 poin per item
        }
        status = "SELESAI";
        return true;
    }

    // Method untuk batalkan order
    public void batalkanOrder() {
        if (status.equals("SELESAI")) {
            System.out.println("Error: Pesanan sudah selesai, tidak bisa dibatalkan");
            return;
        }
        status = "DIBATALKAN";
    }

    // Method untuk display order
    public void displayOrder() {
        System.out.println("=== ORDER #" + orderId + " ===");
        System.out.println("Customer: " + customer.getNama());
        System.out.println("Status: " + status);
        System.out.println("Daftar Item:");
        for (int i = 0; i < jumlahItem; i++) {
            System.out.printf("  - %-20s Rp%.0f%n", items[i].getNama(), items[i].getHarga());
        }
        System.out.printf("Total: Rp%.0f%n", hitungTotal());
    }
}
```

```java
    // Method untuk tampilkan menu tersedia
    public void tampilkanMenuTersedia() {
```

### **1. Deklarasi Class & Atribut**
```java
public class MenuItem {
    private String nama;
    private double harga;

```
#### **Penjelasan:**
- `public class MenuItem`: Mendefinisikan kelas `MenuItem` yang bisa diakses dari luar package.
- **Semua atribut `private`**: Ini **encapsulation** — data disembunyikan dari luar kelas. Hanya bisa diakses via **getter/setter**.
- **Atribut**:
  - `nama`: Nama menu (contoh: "Nasi Goreng").
  - `harga`: Harga dalam rupiah (contoh: 15000.0).
  - `kategori`: Harus salah satu dari `"Makanan"`, `"Minuman"`, atau `"Snack"`.

> 💡 **Mengapa `private`?**
> Agar tidak ada yang bisa mengubah `harga` atau `stok` sembarangan dari luar kelas. Misal: `menuItem.harga = -1000;` → ini **harus dicegah**!

### **2. Constructor Overloading**
```java
// Constructor 1: Stok default 0
public MenuItem(String nama, double harga, String kategori) {
    this(nama, harga, kategori, 0); // Panggil constructor 2
}

// Constructor 2: Dengan stok awal
public MenuItem(String nama, double harga, String kategori, int stok) {
    if (harga < 0) throw new IllegalArgumentException("Harga tidak boleh negatif");
    if (stok < 0) throw new IllegalArgumentException("Stok tidak boleh negatif");
    if (!kategori.equals("Makanan") && !kategori.equals("Minuman") && !kategori.equals("Snack")) {
        throw new IllegalArgumentException("Kategori harus Makanan/Minuman/Snack");
    }

    this.nama = nama;
    this.harga = harga;
    this.kategori = kategori;
    this.stok = stok;
}
```

#### **Penjelasan:**
- **Constructor 1**: Hanya butuh `nama`, `harga`, `kategori`. Stok otomatis di-set ke `0`.
  - `this(...)`: Memanggil constructor lain di kelas yang sama (constructor chaining).
- **Constructor 2**: Lebih lengkap, butuh `stok` juga.
- **Validasi**:
  - Harga/stok tidak boleh negatif → kalau negatif, lempar `IllegalArgumentException`.
  - Kategori harus valid → kalau tidak, lempar error.

> 🔥 **Pro Tip:**
> - **Constructor chaining** (`this()`) menghindari duplikasi kode.
> - **Validasi di constructor** memastikan objek selalu dalam keadaan valid sejak awal.

### **5. Method untuk Stok**
```java

    this.stok += jumlah;

    return true;
}

    return stok > 0;
}
```

> 💡 **Common Mistake:**
> - Lupa validasi `jumlah <= 0` → bisa jadi stok negatif.
> - `kurangiStok()` tidak mengurangi stok jika sudah 0 → return `false`.
